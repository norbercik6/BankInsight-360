# BankInsight-360
Problem biznesowy

Zespół zarządzający potrzebuje przejrzystego raportu umożliwiającego monitorowanie wyników produktów bankowych, aktywności klientów i liczby kontaktów z obsługą.

Cel
Zaprojektowanie dashboardu KPI wspierającego identyfikację trendów i obszarów wymagających dalszej analizy.

Interesariusze
*Kierownik sprzedaży
*Kierownik obsługi klienta
*Analityk biznesowy
*Zespół raportowania

Zakres
*Analiza przychodów według produktu i regionu
*Analiza liczby kontaktów
*Analiza statusów klientów
*Porównanie wyników pomiędzy segmentami

Poza zakresem
*Dostęp do rzeczywistych danych klientów
*Ocena zdolności kredytowej
*Automatyczne podejmowanie decyzji o produktach dla konkretnych osób

Kryteria akceptacji
*Dashboard pokazuje uzgodnione KPI.
*Filtry działają poprawnie.
*Wyniki można uzgodnić z tabelą źródłową.
*Dokumentacja definiuje sposób obliczania każdego KPI.
*Wnioski są oparte na wynikach analizy, a nie na założeniach.

Ograniczenia
Analiza wykorzystuje dane syntetyczne i ma charakter demonstracyjny.
